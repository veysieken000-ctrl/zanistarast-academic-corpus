# Mabûn — ekonomi araştırmaları

Vergisiz toplum bir **tasarım hedefi**, doğrulanmış sürdürülebilir finansman sonucu değil. Kamu hizmetleri, meclis holdinglerinin gelir-gideri, özel girişimler, şok senaryoları, şeffaflık ve dağıtım adaleti için bütçe/stres testi yapılmalı.

Öncelikli makale sorusu: Gelir getiren meclis varlıkları kamusal hizmet yükümlülüklerini hangi koşullarda finanse edebilir?
