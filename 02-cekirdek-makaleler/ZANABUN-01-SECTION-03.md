# ZANABUN-01 — Shared-error variance and effective sample size

Assume each observer reports W_i = theta + B + epsilon_i. B is a centered random error common to all observers with variance tau squared; the epsilon_i are independent centered errors with variance sigma squared, also independent of B. The sample mean K has error variance tau squared + sigma squared / n. Hence increasing n cannot reduce uncertainty below tau squared. For rho = tau squared / (tau squared + sigma squared), the variance-equivalent effective sample size is n_eff = n / (1 + (n-1)rho). When rho is positive, n_eff tends to 1/rho, even as the nominal count grows.

A different model, W_i = theta + b + epsilon_i, has fixed unknown bias b. Its mean squared error is b squared + sigma squared / n. These models are not interchangeable: the first averages over repeated random common errors; the second represents a systematic offset. In the fixed-bias model, (theta,b) and (theta+c,b-c) produce the same observable reports for any c, so the true quantity and shared offset cannot be identified separately without an external reference or constraint. Agreement and repeated measurement are therefore insufficient to identify accuracy. These results are elementary covariance calculations, not new statistical theorems.
