# Mira için salt okunur akademik kaynak sözleşmesi

Bu depo ChatGPT akademik çalışma alanıdır. Mira araştırma sonuçlarını okuyabilir, kaynak göstererek izinli kendi depolarına/hafızasına aktarabilir, hata ve eksikleri kullanıcıya PWA üzerinden bildirebilir. Mira bu depoya yazmaz, değiştirmez, silmez, merge yapmaz. Diğer depolarındaki yetkiler bundan etkilenmez.

**Önemli:** Bu dosya bir **mimari kuraldır**; GitHub token izinlerini teknik olarak kısıtlamaz. Mira tarafında yalnız read izniyle yapılandırma ve gerçek erişim testi ayrıca gereklidir. Public depo okuma erişimine açıktır; yazma erişimi kimlik doğrulama ve GitHub izinlerine bağlıdır.

**Güncel ChatGPT çalışma dalı:** `research/chatgpt-academic-2026-10-20`. `main` yeni dosyaları içermeyebilir. Akademik kaynaklar henüz kanonik hüküm veya hakem onaylı makale sayılmaz. Her kullanımda dosya yolu, sürüm/commit ve kanıt seviyesini belirt.
